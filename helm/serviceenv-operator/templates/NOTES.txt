🚀 Get Started:

1. Check the operator status:
   kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/name={{ include "serviceenv-operator.name" . }}

2. View operator logs:
   kubectl logs -n {{ .Release.Namespace }} -l app.kubernetes.io/name={{ include "serviceenv-operator.name" . }} -f

3. Create your first ServiceEnv:
   cat <<EOF | kubectl apply -f -
   apiVersion: serviceenv.zaeyi.com/v1
   kind: ServiceEnv
   metadata:
     name: dev
     namespace: default
   spec:
     envName: dev
     fallbackEnv: prod
     enabled: true
   EOF

4. Check ServiceEnv status:
   kubectl get serviceenvs -A
